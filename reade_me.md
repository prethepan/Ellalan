# Ellalan – Word Game

Hello Children! 👋  
Welcome to an interesting word game called **Ellalan**.

## Installation Instructions

1. Download or copy the **Ellalan application files** to your computer.
2. Make sure all game files are kept in the **same folder**.
3. No internet connection is required to play the game.
4. If the game is a program file:
   - Double-click the application file to run it, **or**
   - Open it using the required software (for example, Command Prompt or an IDE, if instructed by your teacher).
5. Press **Enter** to start the game once the application opens.

> **Note:**  
> Ensure you have permission to write files in your **Documents folder**, as the game saves results there.

## How to Play

1. Press **Enter** to start the Ellalan application.
2. Enter your **name** and press **Enter**.
3. When asked how many words you want to play:
   - Enter any number **greater than 5** to start the game.
4. Type the **first word**:
   - The word must start with the **first letter of your name**.
   - Press **Enter** after typing the word.
5. The application will suggest a **letter** from the previously typed word.
6. Type a **new word starting with the suggested letter**.
7. Continue until you reach the total number of words you selected.

## Spell Checker

- The game includes a **spell checker**.
- If a word is typed incorrectly, a warning message will be shown and you must try again.

## Rules

- The first word must start with the **initial letter of your name**.
- **Do not use spaces** in words.  
  - Example: ❌ `ice cream` → ✔ `icecream`
- **Do not repeat words**.
  - Repeating a word will end the game immediately.

## Score & File Storage

- Your **score and word details** are saved at the end of the game.
- Data is stored in a file named `game.txt`.
- The file is located in the **Documents folder** of your computer.
